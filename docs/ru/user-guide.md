# Читалка ЛитРес — руководство пользователя

[English version](../en/user-guide.md)

Читалка ЛитРес — приложение для Linux и Windows. Оно показывает книги и аудиокниги, купленные
на ЛитРес, скачивает их и открывает во встроенной читалке и плеере. Ещё оно открывает ваши
собственные книги и статьи (EPUB, FB2, MOBI, PDF) прямо из папок на диске. Оформление в стиле
GNOME, светлая и тёмная тема переключаются вслед за системой. Интерфейс — на русском или английском.

## Установка

### Linux (Fedora, Ubuntu/Debian, Arch)

```
bash install.sh              # установить или обновить
bash install.sh --uninstall  # удалить
```

Приложение ставится для текущего пользователя. `sudo` спросят, только если не хватает системных
библиотек (Python 3.10+, venv, библиотеки для Qt и Chromium). Приложение живёт в
`~/.local/opt/litres-reader`, команда — `litres-reader`, в меню появляется «Читалка ЛитРес»,
файлы EPUB, FB2 и MOBI открываются через неё.

### Windows 10/11

Дважды щёлкните `install.cmd` (или выполните
`powershell -ExecutionPolicy Bypass -File windows\install.ps1`).

Права администратора не нужны. Если Python 3.10+ не найден, установщик поставит Python 3.12
через winget. Приложение живёт в `%LOCALAPPDATA%\Programs\LitresReader`, ярлыки — в меню «Пуск»
и на рабочем столе, EPUB, FB2 и MOBI добавляются в «Открыть с помощью» (программы по умолчанию
не меняются). Удаление — через «Параметры → Приложения».

Первая установка займёт время: PySide6 (Qt со встроенным Chromium) весит около 600 МБ.

## Вход в ЛитРес

Меню → «Войти в ЛитРес». Откроется сайт ЛитРес — войдите как обычно: по паролю, коду из SMS
или через соцсеть. Приложение пароль не видит и не хранит: после входа оно пользуется сессией
встроенного браузера. «Выйти из ЛитРес» (в меню или в «Настройки → Интеграции») стирает сессию;
скачанные книги и прогресс остаются.

## Библиотека

После входа книги из аккаунта загружаются сами. Обновить список — F5 или кнопка слева вверху;
пока окно открыто, библиотека обновляется и сама (по умолчанию раз в 15 минут). Поиск по
названию и автору — Ctrl+F.

**Фильтры** над списком:

- **Статус** — «Все», «Читаю», «Не читал», «Прочитано». Числа на кнопках считают книги
  выбранного источника и подкаталога.
- **Источник** — «Все», «ЛитРес» (под ним «Книги» и «Аудиокниги») и «Мои книги и статьи»
  (под ним разделы своих папок).
- **Подкаталог** — для ЛитРес это ваши папки на ЛитРес (и «Без папки»), для своих книг — папки
  на диске внутри раздела. Выбор папки показывает и книги из её подпапок.
- **Сортировка** — недавние, как на ЛитРес, по названию, автору, сериям, прогрессу, дате покупки.

**Карточка книги.** Нажмите на обложку — книга скачается (EPUB, иначе FB2 или MOBI) и откроется.
Долгое нажатие или правая кнопка мыши открывает меню: читать или слушать, отметка «Прочитано»,
папки ЛитРес, скачать заново, открыть на сайте, следующая книга серии, показать файл, удалить
с устройства. На обложке — прогресс, серия и номер книги; когда книга дочитана, приложение
предлагает открыть следующую в серии.

**Папки ЛитРес:** меню книги → «Папки…». Изменения сразу уходят на ЛитРес, а без сети — при
следующей синхронизации.

**Скачать все книги:** меню → «Скачать все книги…» (или «Настройки → Общие»). Можно выбрать
только книги или книги вместе с аудиокнигами. Книги скачиваются по одной, ход виден в заголовке;
остановить — тем же пунктом меню. В конце появляется итог; книги, которые не скачались,
и причины записываются в журнал.

## Свои книги и статьи

Приложение само находит EPUB, FB2, MOBI и PDF в папках. По умолчанию это три папки
из «Документов»:

| Папка | Раздел |
|---|---|
| `Документы/Books/others` | Другие книги |
| `Документы/articles` | Статьи |
| `Документы/trainings` | Тренинги и презентации |

Папки настраиваются в «Настройки → Общие → Папки»: «Добавить папку…» (приложение спросит
название раздела), «Переименовать…», «Убрать», «Обновить список» (F5 тоже обновляет). Раздел
виден на карточках и отдельным пунктом в фильтре «Источник»; подпапки — в фильтре «Подкаталог».

Файлы открываются на месте: приложение их не копирует, не переименовывает и не удаляет. Место
чтения запоминается, обложка PDF — его первая страница.

## Чтение

- **Листание:** касание левой или правой трети страницы, свайп, стрелки, PageUp/PageDown,
  пробел. Касание середины страницы прячет и возвращает панели — для чтения без отвлечений
  (глава и процент остаются в углах страницы).
- **Панели:** сверху «Назад», «Оглавление», «Вид текста», автолистание, чтение вслух и полный
  экран; снизу — ползунок по книге. Щелчок по ползунку сразу переносит в это место.
- **Вид текста** (кнопка «Аа»): размер шрифта, тема (авто, светлая, сепия, тёмная, чёрная),
  шрифт, межстрочный интервал, поля, ширина строки, две страницы в горизонтальном положении,
  выравнивание по ширине.
- **Жесты:** щипок двумя пальцами или Ctrl+колесо меняют размер шрифта, свайп вверх открывает
  оглавление, свайп вниз прячет или показывает панели.
- **Автолистание:** страница перелистывается сама через заданный интервал (5–120 с).
  Ручное листание начинает отсчёт заново.
- **Чтение вслух:** книга читается с текущего места, предложение подсвечивается, страницы
  и главы листаются сами. Голос системный (Linux — speech-dispatcher, Windows — SAPI).
  Для более естественного русского голоса на Linux поставьте RHVoice
  (`sudo dnf install rhvoice speech-dispatcher-rhvoice` или аналог).
- **PDF** открывается прямо в приложении; страницы показываются как есть, без перекладки текста.
- F11 — полный экран, Esc — выход из полного экрана или назад.

## Аудиокниги

Аудиокниги отмечены значком наушников. Скачивается M4B или архив MP3, затем открывается плеер.

- Главы берутся из разметки внутри M4B (для MP3 — по файлу на главу): список глав с временем
  начала, переход к предыдущей и следующей; ползунок и время — внутри главы.
- Перемотка на −15 и +30 секунд, скорость от 0.75× до 2× без искажения голоса.
- Таймер сна: через заданное число минут или «В конце главы».
- Если уйти в библиотеку, звук не прерывается, а кнопка в заголовке возвращает к плееру.
- Пробел — пауза, стрелки — перемотка.

## Продолжить чтение и автопродолжение

- **Панель «Продолжить чтение»** справа в библиотеке показывает последние начатые книги —
  прочитанные и в приложении, и на телефоне или сайте ЛитРес.
- **При запуске** приложение открывает последнюю текстовую книгу на месте остановки — самую
  свежую из начатых и скачанных, с учётом чтения на ЛитРес. Аудиокниги само не включает.
  Отключается в меню или в «Настройки → Общие».
- **Место с ЛитРес:** если на ЛитРес книга прочитана или прослушана дальше, приложение само
  переходит туда; в уведомлении есть кнопка «Вернуть».
- Дочитанная книга отмечается прочитанной и на ЛитРес.

## Граф книг

Меню → «Граф книг» или Ctrl+G. Граф устроен как в Obsidian: книги и теги — узлы, связь
«книга — тег» — ребро.

- Теги: жанры и теги ЛитРес, ваши папки на ЛитРес, серии, авторы, темы своих книг и статей.
  Виды включаются в панели слева; там же поиск и фильтр «Все / ЛитРес / Мои».
- Наведение подсвечивает связи, щелчок по тегу выделяет его книги, по книге — открывает её.
  Колесо или щипок — масштаб, перетаскивание — сдвиг и перемещение узлов.
- Цвет книги: серый — не начата, акцентный — читаю, зелёный — прочитана.
- Жанры и теги ЛитРес подгружаются в фоне после синхронизации (один раз на книгу). Ход
  раскладки и подгрузки виден в индикаторе сверху и под заголовком окна.

## Статистика чтения

Меню → «Статистика чтения». Минуты сегодня и за неделю, дни подряд, дочитанные книги, график
за две недели и книги, на которые ушло больше всего времени.

Учитывается и чтение на телефоне или сайте ЛитРес: при синхронизации прирост процента
переводится во время (текст — около 1300 знаков в минуту по объёму книги, аудио — по
длительности) и записывается на день, когда читали. На графике эта часть столбика светлее.
Скорость чтения для оценки меняется в «Настройки → Дополнительно».

## Настройки

Меню → «Настройки» или Ctrl+,. Изменения применяются сразу.

| Вкладка | Что в ней |
|---|---|
| **Общие** | язык интерфейса (как в системе, русский, English — после перезапуска); открывать последнюю книгу при запуске; только скачанные; скачать все книги; папки (скачанные книги ЛитРес, свои папки и разделы); статистика |
| **Чтение** | вид текста, чтение вслух, автолистание, скорость аудиокниг |
| **Интеграции** | ЛитРес (вход и выход) и Singularity |
| **Резервные копии** | см. [Резервные копии](#резервные-копии) |
| **Дополнительно** | как часто обновлять библиотеку с ЛитРес и «Обновить сейчас»; скорость чтения для оценки чтения на телефоне; подробный журнал; папки данных, настроек и кэша; сброс настроек |

«Сбросить настройки» возвращает вид текста, чтение, обновление и журнал к исходным; папки,
вход в ЛитРес и библиотека не меняются.

## Резервные копии

«Настройки → Резервные копии».

- **Что в копии:** настройки, библиотека (папки, отметки, пути к скачанным книгам), место
  чтения и закладки, статистика, настройки Singularity. Книги, обложки и вход в ЛитРес в копию
  не входят. Токен Singularity кладётся в копию, только если включено «Сохранять токен Singularity».
- **Когда:** по кнопке «Создать» и автоматически — раз в день или раз в неделю (по умолчанию —
  раз в неделю). Старые копии сверх заданного числа удаляются.
- **Где:** по умолчанию `Документы/Backups/litres-reader`; папку можно сменить. Если папка
  «Документы» синхронизируется с облаком, копии окажутся и там.
- **Восстановление:** из списка последних копий или из файла (например, с другого компьютера).
  Перед восстановлением текущие данные сохраняются в отдельную копию, приложение перезапускается.
  Папки книг и копий остаются как на этом компьютере.
- Файлы копий доступны только вашей учётной записи.

## Singularity

«Настройки → Интеграции → Singularity → Настроить…». Вставьте API-токен из
[личного кабинета SingularityApp](https://me.singularity-app.com) («Доступ к API», с доступом
к задачам, проектам и привычкам) и выберите, что синхронизировать:

- **Задачи «Читаю»** — начатые книги становятся задачами в проекте «Книги»; дочитали — задача
  закрывается.
- **Прогресс в задаче** — процент и текущая глава в заметке задачи.
- **«Хочу прочитать»** — непрочитанные книги становятся задачами в отдельном проекте; начатая
  книга переезжает в «Книги» той же задачей.
- **Ежедневное чтение** — привычка «Чтение N минут» отмечается сама, когда за день набралось
  N минут чтения или прослушивания.

Синхронизация идёт после синхронизации с ЛитРес, при отметке «Прочитано» и раз в пару минут
во время чтения. Свои задачи приложение находит по `externalId`, поэтому дублей не бывает.
Названия проектов и привычек в Singularity всегда на русском — при смене языка интерфейса
дубли не появятся. Токен хранится только на этом компьютере.

## ЛитРес и VPN (Linux)

ЛитРес не открывается через зарубежный VPN. Скрипты в `vpn-bypass/` пускают трафик к ЛитРес
напрямую через обычное подключение, а остальной трафик — через VPN. Если установлен
`vpn-killswitch`, в него добавляется исключение только для адресов ЛитРес.

```
sudo bash vpn-bypass/install.sh           # установить
sudo bash vpn-bypass/install.sh --remove  # удалить (и вернуть исходный kill switch)
```

## Где хранятся данные

| Что | Linux | Windows |
|---|---|---|
| Книги, обложки, библиотека, прогресс | `~/.local/share/litres-reader/` | `%LOCALAPPDATA%\litres-reader\` |
| Сессия ЛитРес | `~/.local/share/litres-reader/webengine/` | `%LOCALAPPDATA%\litres-reader\webengine\` |
| Настройки, токен Singularity | `~/.config/litres-reader/` | `%APPDATA%\litres-reader\` |
| Кэш (значки сервисов) | `~/.cache/litres-reader/` | `%LOCALAPPDATA%\litres-reader\cache\` |

Папку для скачанных книг можно сменить в «Настройки → Общие → Папки». Файлы данных создаются
с доступом только для владельца. Скачанные книги и прогресс остаются и после удаления приложения.

| Ctrl+F | поиск |
| Ctrl+O | открыть файл |

## Ограничения

- У ЛитРес нет открытого API. Приложение использует те же адреса, что и сайт; если ЛитРес их
  поменяет, список книг или скачивание перестанут работать.
- Книги с DRM, а также доступные только для онлайн-чтения на сайте, не откроются.
- Точное место чтения на ЛитРес не записывается — только отметка «Прочитано».
- Автоматических переносов слов нет: встроенный Chromium не содержит словарей переносов.
- PDF показывается постранично как есть; изменить размер шрифта в PDF нельзя.
