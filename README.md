# Читалка ЛитРес

Приложение для GNOME: показывает книги, купленные на ЛитРес, скачивает их
и открывает во встроенной читалке. Также открывает свои файлы EPUB, FB2, FB2.ZIP и MOBI.

## Установка

```
bash ~/litres-reader/install.sh
```

Скрипт ставит зависимости (Fedora или Ubuntu): PyGObject, GTK 4, libadwaita,
WebKitGTK 6.0 и словарь русских переносов `hyphen-ru`. Затем добавляет «Читалку ЛитРес»
в меню приложений. Запуск без установки: `python3 ~/litres-reader/litres_reader.py`.

## Как пользоваться

- **Вход:** меню → «Войти в ЛитРес». Откроется сайт ЛитРес, войдите как обычно
  (по паролю, коду из SMS или через соцсеть). Приложение пароль не видит и не хранит,
  оно только пользуется сессией браузера после входа.
- **Библиотека:** после входа книги из аккаунта загружаются сами. Обновить список: F5
  или кнопка слева вверху. Аудиокниги не показываются.
- **Скачать и читать:** нажмите на обложку. Книга скачается (EPUB, иначе FB2 или MOBI)
  и откроется. Долгое нажатие или правая кнопка мыши открывает меню: скачать заново,
  удалить с устройства, открыть на сайте.
- **Листание:** касание левой или правой трети страницы, свайп, стрелки,
  PageUp/PageDown, пробел. Касание середины показывает и скрывает панели.
  F11 — во весь экран, Esc — выход из полноэкранного режима или назад.
- **Вид текста** (кнопка «Аа»): размер шрифта, тема (авто, светлая, сепия, тёмная,
  чёрная), шрифт, межстрочный интервал, поля, ширина строки, две страницы
  в горизонтальном положении, выравнивание, переносы.
- **Место чтения** запоминается для каждой книги.

## ЛитРес и VPN

ЛитРес не открывается через зарубежный VPN. Скрипт в `vpn-bypass/` пускает трафик
к ЛитРес напрямую через обычное подключение (Wi-Fi/Ethernet), а весь остальной
трафик по-прежнему идёт через VPN:

```
sudo bash ~/litres-reader/vpn-bypass/install.sh           # установить
sudo bash ~/litres-reader/vpn-bypass/install.sh --remove  # удалить
```

Маршруты ставятся при каждом подключении VPN или смене сети (хук NetworkManager),
а раз в 30 минут таймер обновляет адреса доменов ЛитРес. Посмотреть их можно командой
`ip route show proto 247`.

## Где что хранится

| Что | Где |
|---|---|
| Книги, обложки, прогресс | `~/.local/share/litres-reader/` |
| Сессия ЛитРес (куки) | `~/.local/share/litres-reader/session/` |
| Настройки вида | `~/.config/litres-reader/settings.json` |

«Выйти из ЛитРес» стирает сессию. Скачанные книги и прогресс остаются.

## Ограничения

- У ЛитРес нет открытого API. Приложение использует те же адреса, что и сайт
  (их выяснил проект [bookvault](https://github.com/mavrovde/bookvault)).
  Если ЛитРес их поменяет, список книг или скачивание перестанут работать.
- Книги с DRM, а также доступные только для онлайн-чтения на сайте, не откроются.
- PDF открывается в программе, которая назначена для PDF в системе.
- Отладка: `LITREADER_DEBUG=1 python3 litres_reader.py` выводит запросы и
  включает инспектор WebKit (правая кнопка → «Inspect Element»).

## Состав

- `litres_reader.py` — приложение (GTK 4 + libadwaita + WebKitGTK 6).
- `web/reader.*` — страница читалки.
- `web/litres-hook.js` — встраивается в сайт ЛитРес и передаёт приложению служебные
  заголовки API. Пароль и формы не трогает.
- `web/foliate/` — движок отображения книг [foliate-js](https://github.com/johnfactotum/foliate-js)
  (лицензия MIT, версия в `web/foliate/VERSION`).
